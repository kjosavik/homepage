# Asset sources

[erik3.jpg](../site/assets/erik3.jpg) is the selected hero portrait and the only photo in the publish directory. The logo sources below are references, not permission to republish.

The Black Speech option uses [Alcarin Tengwar](https://github.com/Tosche/Alcarin-Tengwar/tree/a4530d430ea01871b0b0a54d1de218d2ffde0ea5) by Toshi Omagari. The self-hosted webfont is distributed under the [SIL Open Font License](../site/assets/Alcarin-OFL.txt).

Keep cleared assets in `site\assets\logos` when added. Prefer SVG or transparent PNG from the organization, record any usage conditions here, and keep each CV link working regardless of whether it displays a logo or text.
